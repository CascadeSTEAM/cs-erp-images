## Decisions Made

- **The 9 "route collisions" are not a defect — do not fix them.** Nine `Website Entry` routes
  are shadowed by the legacy Builder Pages they will replace. The flat `:slug` scheme in the
  content model *relies* on static routes resolving before dynamic ones. Sequence: build the
  `:slug` template → verify each of the nine renders → *then* retire the old page, one at a
  time. Retiring early 404s nine live URLs; renaming breaks the inbound links the flat scheme
  exists to preserve.
- **Index pages route at `community-groups` / `community-projects`**, not the content model's
  `groups` / `projects`. `migrate_content.py`'s `SECTION_ROUTES` already decided this, those
  are the real legacy URLs, and the 31 live bodies point there. `groups` / `projects` become
  redirects. (This reverses an earlier call made in this same session.)
- **The Projects index is flat.** The content model says split it by Community Building /
  Community Service. That grouping is real — 7 + 6 = the 13 Project entries exactly — but it
  lives on the **home page** as prose. `Projects/index.md` is flat and alphabetical, and no
  entry field encodes the grouping. Making it data-driven needs a `category` Select; that is a
  schema change and therefore a decision, not a gap-fill.
- **`published = 1` on all 31 stays.** All were public on the legacy site. The definition's
  `default 0` still correctly governs newly authored entries. Revisit at go-live.
- **`Event.location` custom field abandoned** — core `Event` already ships one. Corrected the
  definition file, not the site. Follow-up: `rsvp_url.insert_after` should be `banner`, which
  keeps the website block contiguous at indices 3–7.
- **`event_type` hidden *with* a `Public` default.** Hiding a `reqd: 1` field with no default
  would have made the Event form unsubmittable — almost certainly why the earlier run stopped
  at 18 of 19 property setters.
- **Scope rule set by the owner: do not work tickets assigned to other people.** CS-0063 is
  Brittin Kellar's and is dropped, including the meta-work of making it visible to them.
